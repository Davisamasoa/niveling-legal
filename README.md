# niveling-legal

Política de Privacidade do app Niveling, publicada pelo GitHub Pages em
https://davisamasoa.github.io/niveling-legal/ (o app e a Play Store apontam
para esse endereço; o link de exclusão de conta usa `#apagar-conta` — não
renomear essa âncora).

- `index.html` — a página inteira (estilos dentro do arquivo).
- `en/index.html`, `es/index.html` — a mesma política em inglês e espanhol
  (o app abre a do idioma dele). Mudou o texto em português: mudar as três.
- `fonts/` — fontes do app, servidas daqui (sem Google Fonts).
- `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` — o logo do Niveling.

Ao mudar o texto: atualizar a data "Última atualização" e, se a mudança
exigir novo aceite no app, `PRIVACY_VERSION` em
`niveling-app/src/constants/legal.ts`. Esta é a versão oficial da política
(a de `niveling-app/docs/privacy/` é só um rascunho antigo).
